# Name research (Part A) - checked 2026-11-05

The locked name stays Techserva. This file is ongoing research only. Comments on "feel" are my interpretation, not measured fact.

## 1. Patterns in real IT-service brand names

Sourced facts are limited; many name meanings are not stated on the pages I could read.

- Accenture: coined from "accent" + "future"; picked because the word was meaningless and inoffensive in all markets. https://en.wikipedia.org/wiki/Accenture , https://www.fortune.com/2025/10/26/the-story-behind-accenture-name-arthur-andersen-25th-anniversary
- Cognizant: founded 1994 in Chennai, renamed from Dun & Bradstreet Satyam Software to Cognizant Technology Solutions in 1997. A real word, not a service word. https://en.wikipedia.org/wiki/Cognizant
- Infosys: incorporated 1981 as Infosys Consultants (later Infosys Technologies). Name meaning not stated on the page. https://en.wikipedia.org/wiki/Infosys
- Globant (2003, Buenos Aires): coined; meaning not stated on Wikipedia. https://en.wikipedia.org/wiki/Globant
- Thoughtworks: name coined by founder Roy Singham in 1990. https://en.wikipedia.org/wiki/Thoughtworks
- Names I know from memory but did NOT verify: Rackspace, Kaseya, ConnectWise, NinjaOne, Datto, Toptal, Endava, EPAM, Wipro, Netguru. Indonesian examples (Dicoding, Telkomsigma, Metrodata, Qiscus, Kata.ai) were NOT researched.
- Small firms that surfaced in search, so names already in use in this niche: gTECHserv, Techservice (Tbilisi MSP), TechServ IT, TECHSERVE IT & INTERNET SOLUTIONS LTD, NetCraftsmen, SysMind, TechnoWright (sources in section 4).

Patterns (sourced ones plus the candidate checks):
1. Coined or clipped words that do not describe the offer (Accenture, Cognizant, Globant, Infosys). Nothing says "menu" or "service desk".
2. Craft compounds: -works, -wright, -smith, -mason, -forge. Tech root + maker noun. Sounds like a team that builds, not a catalogue.
3. Real-word abstractions (Cognizant, Thoughtworks).
4. Tech root + serv/ops/sys/stack/net compounds: easy to read as IT, but very crowded (almost every -works/-craft/-forge/-bridge combo returned 200 on Vercel, .xyz and .com).
5. My reading of why the owner's rejects felt wrong: they describe the offer literally (JasaIT, IT Service Menu, ITServed), use a mascot trade (Butler, Tailor, Medic, Crew), or look like a local shop sign (BengkelTek, TukangIT, Layantek).

## 2. Method

Per candidate: `https://<n>.vercel.app`, `https://rdap.centralnic.com/xyz/domain/<n>.xyz`, `https://rdap.verisign.com/com/v1/domain/<n>.com`. 404 = not registered at that source, 200 = taken. Other codes (451, 500, 307) are listed as-is and are not "free". A Vercel 404 only means no project with that subdomain. Run from this machine on 2026-11-05.

Porkbun public pricing API (https://api.porkbun.com/api/json/v3/pricing/get), read live today: .xyz registration 2.04, renewal 14.21, transfer 14.21 USD.

## 6. Recommendation (5)

None is clearly better than Techserva on "IT-service feel"; they trade a free .xyz for a taken .com.

1. **Techwright** (techwright.xyz, 2.04 USD) - "wright" = maker, reads like an engineering shop. Weakness: TechnoWright already exists, .com taken, slightly archaic.
2. **Stackhaul** (stackhaul.xyz) - stack + haul, suggests moving heavy work. Weakness: "haul" can read as logistics; no sourced precedent.
3. **Sysmend** (sysmend.xyz) - sys + mend, clearly IT. Weakness: sounds like repair only, close to SysMind.
4. **Vantaops** (vantaops.xyz) - coined, ops-flavoured, in the Accenture/Globant style. Weakness: "Vanta" is a known compliance-software brand, so a trademark clash in security is likely; not web-searched.
5. **Servastack** (servastack.xyz; .com also free) - closest to Techserva, the only one with free Vercel, .xyz and .com. Weakness: less distinctive, sounds like a hosting product, not web-searched.

Keeping Techserva is also defensible: Vercel and .xyz free, no exact company found, but .com taken and confusable with TechServ/Techserve names.
